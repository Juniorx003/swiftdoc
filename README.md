# SwiftDoc Studio Pro (SD)

Aplicativo web completo (Triple-Engine: Documentos PDF, Foto & Vídeo/Motion) pronto para hospedagem gratuita no GitHub Pages.

## Novidades desta versão:
1. **Limpeza de Recentes**: Opção dedicada para remover arquivos recentes da lista (estilo Adobe Acrobat).
2. **Sem abertura forçada de arquivos**: Ao clicar em Booklets, Photo ou Motion, a interface abre em estado limpo caso o usuário não tenha selecionado um arquivo.
3. **Open File direto**: O botão Open File na Home abre a janela de seleção e joga o usuário imediatamente no motor correspondente (PDF, Foto ou Vídeo).
